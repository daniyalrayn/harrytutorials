# Harry Tutorials Website — Version 4

## Upload to GitHub Pages

Upload the **contents of this folder** to the root of your `daniyalrayn/harrytutorials` repository and commit to `main`.

Required structure:

- index.html
- courses.html
- quiz.html
- about.html
- testimonials.html
- contact.html
- guarantee.html
- thailand.html
- style.css
- script.js
- assets/harry-home.png

Then enable GitHub Pages from Settings → Pages → Deploy from branch → main → / (root).

## Editable details

- Contact email/phone/WhatsApp: `contact.html`, `script.js`, and footer in page templates.
- Lecturer information: `about.html`.
- Course content: `courses.html`.
- Offers/terms: `guarantee.html` and `thailand.html`.
- Homepage content: `index.html`.
- Main artwork: `assets/harry-home.png`.

The homepage is no longer a static poster: the artwork is retained as a visual element, while all major website content is live HTML and editable.
